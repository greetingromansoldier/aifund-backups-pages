AIFund Backups

Privacy policy

Effective date: October 4, 2026

This policy describes the intended data handling of AIFund Backups, an operator-managed utility built around rclone. It is for authorized AIFund operators, not a public trading or file-sharing service.

Purpose and backup data

The utility uses Google Drive to store encrypted backup archives and related recovery information. Archives may contain confidential operational data. The required procedure encrypts that data before upload and keeps the private decryption key separately from the backup host.

This public website does not contain or provide access to those archives. It does not collect trading credentials or accept uploads.

Google Drive permissions

The utility requests https://www.googleapis.com/auth/drive.file, not full-Drive access. This permission is used to create backup folders, upload and read backup files, verify transfers, and delete files when an operator applies the configured retention policy.

Google Drive data and file metadata are used only for backup, verification, retention, and recovery. The utility does not request Gmail, contacts, or calendar access.

Authorization credentials

Authorization is provided through Google OAuth. The utility does not collect the Google account password. Access and refresh tokens are stored in rclone configuration files on authorized operator devices and, when needed, on the backup host for unattended transfers.

Those configuration files must be restricted to authorized operators and kept outside public repositories and this website. Tokens are used only to perform the authorized Google Drive operations.

Access and sharing

Backup access is limited to operators authorized by AIFund. The utility does not publish backups, sell Google user data, or use that data for advertising. Google processes storage and authorization as the service provider under its own policies.

Retention and removal

Operators set archive retention in the backup configuration. This website does not establish a fixed retention period. An authorized operator can remove backup files from Google Drive and remove stored authorization credentials from the devices and hosts that use them. Contact the address below for a removal request.

How to revoke Google access

The account owner can revoke access from Google Account connections by selecting AIFund Backups and removing its access. This stops future authorized API access; it does not delete backup files already stored in Drive. File removal is a separate action.

This information website

These static pages have no forms, analytics scripts, or application cookies. The hosting provider may process normal web request data, such as an IP address, to serve the pages. When hosted on GitHub Pages, that processing is covered by the GitHub privacy statement.

Contact and policy updates

For questions, access requests, or removal requests, contact ai.fund.info@gmail.com. Changes to this policy will be published here with an updated effective date.
